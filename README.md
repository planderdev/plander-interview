# 플랜더 인터뷰

플랜더 구성원이 대표 없이도 고객 미팅을 진행하고, 들은 내용을 정리해 고객과 공유하고, 의뢰로 전환하도록 돕는 사내 도구입니다.

## 인터뷰 한 건에 담는 것

| 구역 | 내용 | 고객 공유 |
|---|---|---|
| 미팅 정보 | 웍스 고객 불러오기, 고객사, 일시, 장소, 방식, 플랜더 참석자, 진행 상태 | 고객사, 일시 |
| 상대측 미팅자 | 이름, 직함, 연락처, 결정 역할(결정권자, 실무 담당, 참고인), 메모 | 이름과 직함만 |
| 고객 사업 | 업종, 사업 형태, 단계, 지역, 운영 채널, 설명 | 고르면 |
| 원하는 일 | 목표, 지금 겪는 문제, 바라는 결과, 시작 시점, 예산, 결정 시점 | 고르면 (예산, 결정 시점 제외) |
| 플랜더가 할 수 있는 일 | 플랜더 단가표에서 고른 항목과 수량, 예상 금액 | 고르면 (금액은 따로 고름) |
| 외부 협력이 필요한 일 | 분야, 협력사, 예상 비용, 상태 | 나가지 않음 |
| 요약 정리 | 한 줄 요약(내부), 고객용 정리, 위험 요소, 다음 할 일, 내부 메모 | 고객용 정리, 다음 할 일 |
| 공유 범위 | 내부 공유 범위, 고객 공유 링크와 항목 | |
| 의뢰 전환 | 전환 준비 체크, 웍스 클라이언트와 프로젝트 생성 | |

## 기존 고객 불러오기

미팅 정보 맨 위의 "웍스 고객 불러오기"로 플랜더웍스에 등록된 고객을 찾습니다. 불러오면 고객사 이름을 채우고, 비어 있는 업종, 웹사이트, 지역, 담당자 연락처만 채웁니다. 이미 적은 내용은 덮지 않습니다. 연결된 고객의 웍스 프로젝트와 다른 인터뷰도 함께 보입니다. 고객사 이름이 웍스 고객과 같으면 연결을 권합니다.

## 진행 상태

작성중 → 정리 완료 → 제안중 → 의뢰 전환, 또는 보류. 의뢰 전환은 전환 버튼으로만 됩니다.

## 내부 공유 범위

| 범위 | 볼 수 있는 사람 |
|---|---|
| 팀 전체 | 웍스 계정이 있는 구성원 모두 |
| 운영자와 참석자 | 운영자 이상, 작성자, 플랜더 참석자 |
| 참석자만 | 작성자, 플랜더 참석자, 슈퍼운영자 |

고칠 수 있는 사람은 볼 수 있는 사람 중 작성자, 참석자, 운영자 이상입니다.

## 의뢰 전환

"의뢰로 전환"을 누르면 웍스에 다음을 만들고 인터뷰에 연결합니다.

- 클라이언트: 미팅 정보에서 웍스 고객을 불러왔으면 그 고객에 붙입니다. 아니면 같은 이름의 고객에 연결하거나 새로 만듭니다(관계 단계 상담중, 담당자 전환한 사람).
- 프로젝트: 상태 대기, PM 전환한 사람, 카테고리와 예산(기본값은 고른 항목의 공급가), 목표는 "바라는 결과", 설명에는 요약과 고른 항목이 들어갑니다.

## 공유 페이지 두 가지

| 페이지 | 주소 | 누가 보나 | 담기는 것 |
|---|---|---|---|
| 외부 공유 (고객용) | `/s/<토큰>` | 링크를 받은 사람 누구나, 로그인 없음 | 공유 범위에서 고른 항목만. 연락처, 외부 협력, 내부 메모, 위험 요소, 예산, 결정 시점은 빠짐 |
| 내부 공유 (플랜더용) | `/interviews/<id>/brief` | 내부 공유 범위 안의 웍스 구성원, 로그인 필요 | 인터뷰 기록 전부 (읽기 전용) |

편집 화면의 "공유 범위"에서 두 링크를 열거나 복사합니다. 외부 링크는 껐다 켜면 주소가 바뀌어 예전 링크가 막힙니다.

## 로컬 실행 (배포 전)

```bash
npm install
npm run dev   # http://localhost:3200
```

- 환경 변수(`.env.local`)가 없으면 목업 모드로 열립니다. 로그인 없이 바로 들어갑니다.
- 입력한 예시 데이터는 `.local-data/mock-db.json`에 저장되어 서버를 다시 켜도 남습니다. 이 폴더는 git 에 올라가지 않습니다.
- 처음 예시로 되돌리려면 `npm run reset:local` 후 서버를 다시 켭니다.
- 헤더의 "보는 사람"으로 슈퍼운영자, 운영자, 팀원을 바꿔 가며 내부 공유 범위가 맞게 막히는지 볼 수 있습니다.
- 같은 와이파이의 다른 기기에서 보려면 `npm run dev -- -H 0.0.0.0` 로 켜고 `http://<이 맥의 IP>:3200` 으로 엽니다.

실제 DB 연결과 배포는 [docs/설치.md](docs/설치.md)를 보세요. 실제 DB를 연결하면 목업 데이터 파일은 쓰지 않습니다.

## 기술

Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS, Supabase (Auth, PostgreSQL). 플랜더 웍스와 같은 계정, 같은 DB를 씁니다.
